We color each element of the set $\{1,2,\cdots ,1000\}$ red or blue. Then we arrange the red elements in a Standard Young Tableau $S$ and the
blue elements in a Standard Young Tableau $T$ so that the column lengths of both $S$ and $T$ come from the set $\{2,4,6,8,10\}$.
In how many ways is this possible? Provide the first ten digits and the last ten digits of the answer.
