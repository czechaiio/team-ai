Let $G$ be a matrix in $F_3^{4\times n}$ with rows such that for every vector list of 287 vectors $v_1,\ldots,v_{287}$ (there can be repetition) in ${F_3}^4$ I can find $287$ disjoint subsets $X_1,\dots,X_{287}$ of columns of $G$ such that $v_i$ belongs to the span of the columns of $X_i$. Let $C$ be a linear code generated by a matrix with the property described above that minimise $n$. What is the weight enumerator of a code generated by such a $G$?
